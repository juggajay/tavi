# Tool list

Generated by `node scripts/public/tools.mjs` in the private working repository. The reader follows the group list in `src/hq/toolbox/tools.ts`, reads each factory and included page factory as TypeScript syntax, and lists every literal tool name. It does not run the tool code. Run it after tool changes; review a changed group layout before exporting. Input fields, descriptions and permission checks live at the linked source lines.

The names below are exact tool handles. A job card grants groups; a listed tool is not permission to use it. Sign-in, approval, safety and test-turn checks still apply. Provider connectors and the engine’s own Linux tools are separate and depend on setup.
