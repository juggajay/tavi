# Changes

These dates describe capabilities in the source. They are not a claim that every feature has been tried on every PC or phone. Installation and release review still matter.

## 20 November 2026

- A separate Windows program, icon and keeper can run Tavi beside an earlier app.
- Public web search and page reading check outgoing words for private details and retain source addresses.
- Bots with computers can keep answering while separate longer work runs.
- The app can refresh its build, offer provider model lists and show a smaller live screen with control access.
- Quiet looks run on the lead's own separate turn, with limits and priority for the user's requests. Scheduled looks remain a deliberate user choice.

## 19 November 2026

- A team view, independent bot conversations and job cards, model choices, fallbacks, characters and colours.
- Shared subscription sign-in, with the user doing the sign-in themselves.
- Separate safety guard with Pause, Wall off, Kill and a PIN for reopening.
- Phone team view, voice routing, group answers and watch-only screen access.
- Longer work with visible steps, limits, stop and steering; scoped memory and written hand-overs.
- Bots can ask one another bounded questions without inheriting the lead's whole conversation.
- Searchable pages with filters, pictures and a saved self-contained HTML file.
- Drawing and model tools retained, including off-screen model checks where the renderer is installed.

## 18 November 2026

- Dedicated Linux space, pinned Hermes install, ordinary bot users, network boundaries and start probes.
- Checked toolbox adapter using the shared TypeScript tools, per-bot access and approval checks inside calls.
- Queue and engine events converted to readable conversation steps and progress.

## Public edition

- Explicit copy list, exact cleaning rules, private-list and pattern scan, portable type/test proof and a last-made record.
- Separate public history; local clone update with optional local commit and no automatic push.
- Public guides and source-generated tool list. No personal data, working notes or provider sign-ins are supplied.
