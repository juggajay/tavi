# Changes

These dates describe capabilities in the source. They are not a claim that every feature has been tried on every PC or phone. Installation and release review still matter.

## 25 November 2026

- Pages have a cover, quick facts, grouped tick lists and clear steps, with amounts apart from names and warnings beside the action. Recipes, plans, guides and comparisons arrive as pages you can follow and keep.
- Start cooking opens a large working view. Go back, read ahead, swipe between steps on a phone, or return to All steps. Ticks and your place are remembered on this device.
- Pictures of generic dishes and methods can be made on the PC and arrive one at a time while you read. They are labelled as made by AI. Real things still use real pictures. If making pictures is unavailable, the words are ready anyway.
- Saved page files work without a connection, including pictures, ticks, search and the working view. Pictures still on their way are left out of the saved file. Printing gives a clean page with empty tick boxes.
- Timers, changing the number of serves, unit conversion and maps on a plan are not included.
- **Change a bot's look by asking.** Ask to see the choices, name a shape or icon, or say "make yourself blue". The choice stays until you change it again and appears across your open screens and the bot's computer. The phone now has the same shapes, icons and colours as the desktop, under "Change its look" in a bot's details.

## 24 November 2026

- A call starts cleanly. The screen shows it listening, and two soft notes play, only once the call's link is really up; before, words said in the first second or two could be lost. A bare hello ("hello", "can you hear me?") is answered at once without a bot's turn, in about two seconds where it took about ten.
- How long each call took to set up (microphone, the device's network check, the voice service) is kept in the record, for when a start feels slow.

## 21 November 2026

- Tavi has its own look: a family of soft, rounded bots as the mark and the icon, its own lettering, and orange with green and blue on charcoal or stone. Every icon and picture is made from the drawings by one script. Your own messages keep the colour of the bot you are talking to.
- A first-run welcome: name the main bot, sign in, choose a PIN, then the main bot gets to know you in conversation and shows a page of what it knows that you can correct. "Get to know me better", "what do you know about me?" and "forget that" work at any time.
- One command installs, checks, starts, stops, updates and removes the system (`node scripts/tavi.mjs`). It was run for real on a clean Linux space, which found and fixed six faults; it now also installs the Python tools that read documents.
- The safety switch works on the bots' own Linux space under a name that starts with `tavi-`, and refuses any other.
- A wallpaper that a strict reader refused could stop a bot's computer from starting. Fixed, and tested for every shape and colour.
- The test runner gives a failed file one more try by itself and names any test that needed it. The screen tests were brought up to date and pass in full.

## 20 November 2026

- A separate Windows program, icon and keeper can run Tavi beside an earlier app.
- Public web search and page reading check outgoing words for private details and retain source addresses.
- Bots with computers can keep answering while separate longer work runs.
- The app can refresh its build, offer provider model lists and show a smaller live screen with control access.
- Quiet looks run on the lead's own separate turn, with limits and priority for the user's requests. Scheduled looks remain a deliberate user choice.

## 19 November 2026

- A team view, independent bot conversations and job cards, model choices, fallbacks, characters and colours.
- Shared subscription sign-in, with the user doing the sign-in themselves.
- Separate safety guard with Pause, Wall off, Kill and a PIN for reopening.
- Phone team view, voice routing, group answers and watch-only screen access.
- Longer work with visible steps, limits, stop and steering; scoped memory and written hand-overs.
- Bots can ask one another bounded questions without inheriting the lead's whole conversation.
- Searchable pages with filters, pictures and a saved self-contained HTML file.
- Drawing and model tools retained, including off-screen model checks where the renderer is installed.

## 18 November 2026

- Dedicated Linux space, pinned Hermes install, ordinary bot users, network boundaries and start probes.
- Checked toolbox adapter using the shared TypeScript tools, per-bot access and approval checks inside calls.
- Queue and engine events converted to readable conversation steps and progress.
